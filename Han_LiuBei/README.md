# 汉帝国 — 刘备：桃园结义 v0.15

风云变幻规则集的新文明「汉帝国」，领袖刘备。尚未实机验证。

## 文明特性

- **兴复汉室**：陆地作战单位迎战基础战斗力更强的单位时 +5 战斗力（与高卢 Gaesatae 同一需求条件）。不是本文明建立的城市每回合 +3 忠诚度。
- **蜀道**：陆地单位（含平民、支援单位）进入丘陵不额外消耗移动力（同阿尔卑斯训练）。山脉为商业中心 +1 金币、为工业区 +1 生产力的标准相邻加成（同马丘比丘的修改器，可叠加）。
- **屯田**：每个单位维护费 -1（同征兵政策）。兵营及其建筑不再产出大将军点数，改为兵营 +2 生产力、其中每座建筑（兵营、马厩、军械库、军事学院，以及征服模式激活来的 Ordu / Basilikoi Paides）再 +2 生产力：区域点数用 `MODIFIER_PLAYER_DISTRICTS_ADJUST_GREAT_PERSON_POINTS` 负数抵消（征服模式去掉 Thanh 点数的同一写法），建筑点数用 `MODIFIER_PLAYER_CITIES_ADJUST_GREAT_PERSON_POINT` 按“城市拥有该建筑”抵消（同斯德哥尔摩城邦的写法，负数是第一次用，需要实测）。与兵营相邻的所有改良设施（农场、矿山、种植园、营地、牧场、采石场等）+1 粮食、+1 生产力。

## 领袖能力：桃园结义

- **桃园结义**：建立首都及研究特定科技时五虎上将免费加入。所有单位战斗经验 +100%（`MODIFIER_PLAYER_UNITS_ADJUST_UNIT_EXPERIENCE_MODIFIER`，政策「测量」给侦察单位用的同一个修改器，不加兵种条件）。游戏内领袖能力只写这一句，细节写在各武将的单位说明里。
- **厚施恩德，以收众心**：城市施加的忠诚度压力 +50%（与黄金时代同一修改器 `MODIFIER_PLAYER_CITIES_ADJUST_IDENTITY_PER_CITIZEN`，Amount 0.5，可叠加）。因忠诚度叛离其他文明的城市，在本文明忠诚压力最高时跳过自由城市直接归降（复用埃莉诺的 `SKIP_FREE_CITY`）。

### 五虎上将

武将不能训练或购买，达成条件后由 `Scripts/HanTigers.lua` 免费放到首都旁：关羽、张飞在建立首都的当下（`GameEvents.CityBuilt`），其余在研究到对应科技后的下一个回合开始时。每位武将一局只送一次，阵亡后不再出现。没有维护费，可以获得经验和晋升，不能升级。

| 关羽 | 重骑兵 | 建立首都 | 34 | 4 | 武圣：进攻 +5；万军丛中：无视区域控制；斩首：进攻后敌方单位剩余生命值 ≤20 直接斩杀；过五关斩六将：击杀后恢复 20 生命值 |
| 张飞 | 抗骑兵 | 建立首都 | 32 | 3 | 万人敌：防守 +7（抗骑兵兵种对骑兵另有 +10） |
| 赵云 | 轻骑兵 | 骑术 | 30 | 5 | 七进七出：无视区域控制，攻击后仍可移动 |
| 黄忠 | 远程 | 机械 | 22 / 远程 32，射程 2 | 3 | 老当益壮：受伤不降战斗力；定军山：对满生命值单位 +5 |
| 马超 | 轻骑兵 | 马镫 | 32 | 5 | 西凉铁骑：侧翼加成 +100%；锦马超：对骑兵 +5 |

五虎将共有：

- **统率**：2 格内（含自身所在格）的己方陆地作战单位 +5 战斗力、+1 移动力，不受时代限制。范围条件复用大将军光环的 `AOE_REQUIRES_OWNER_ADJACENCY`（0~2 格）和 `AOE_REQUIRES_LAND_DOMAIN`，受益兵种照抄大将军能力的标签，但用的是自己的能力，所以**可以和大将军叠加**；同一个能力只生效一次，多位武将之间不叠加。张飞「长坂断后」的再 +5、赵云「虎威将军」的再 +1 移动是另外的能力，也会叠加。
- **虎将之勇**：生命值低于 50 时 +7 战斗力，低于 25 时再 +7，用来保命。原版没有按自身生命值判断的战斗需求条件（`REQUIREMENT_UNIT_DAMAGE_MINIMUM` 在战斗里判断的是对手，「溃败」晋升就是这么用的），由 `Scripts/HanTigers.lua` 在回合开始、回合开始结算完成和每次战斗后按生命值用 `ChangeAbilityCount` 开关三档能力。张飞晋升「血战不退」后低于 75 也 +7。
- **关羽斩首**：关羽进攻后，被攻击的敌方作战单位若还活着且剩余生命值 ≤20（晋升「威震华夏」后 ≤35），由 `Scripts/HanTigers.lua` 在 `GameEvents.OnCombatOccurred` 里用 `UnitManager.Kill` 斩杀。只对单位，不对城市 / 区域；关羽防守时不触发。
- **关羽威震华夏**（终极晋升）：关羽在战斗中杀死敌方单位（进攻、防守反杀、斩首都算）时，以关羽所在格为中心 9 格内、与你交战的城市各 `ChangeLoyalty(-20)`，城市上方飘字提示。同样在 `GameEvents.OnCombatOccurred` 里实现，按玩家编号顺序遍历城市，联机各端一致。

关羽对标骑士：远古 34，中世纪成长到 50，与骑士相同，另有进攻 +5。

随时代成长：玩家时代从古典起每升一档，五虎上将 +8 战斗力（远程攻击同样生效），战斗预览里每个时代一行。实现方式是每个时代一个能力，由领袖特性的 `MODIFIER_PLAYER_UNITS_GRANT_ABILITY` 在 `REQUIREMENT_PLAYER_ERA_AT_LEAST` 满足时授予。

定位：关羽万军丛中斩将破城；张飞防守和残血硬抗、贴身削弱敌军；赵云侧重机动（移动、渡河、登船、视野、隐身、两次攻击）；马超专打骑兵（克骑兵、俘获骑兵、反克抗骑兵）。

机制类晋升都复用原版现成的修改器：刮骨疗毒 = 医疗兵回血（相邻含自身），义释严颜 = 私掠船「战利品」的俘获，喝断当阳桥 = 毛利 Toa 的相邻敌军减战斗力，汉水空营 = 隐身（伪装晋升），截江夺斗 = 两栖 / 红衫军的登船上岸，虎威将军的移动光环 = 大将军移动加成的写法，羌胡归心 = 秦始皇（一统天下）收编蛮族，收服庞德 = 成吉思汗进攻时俘获骑兵，西凉旧部 = 「掠夺」晋升的劫掠只耗 1 移动。其中**俘获和收编蛮族原版只用在海军 / 近战 / 蒙古骑兵上，用在张飞和马超身上需要实测**。

晋升树里的「血战不退」（虎将之勇多一档）和「威震华夏」的斩首线提高没有修改器，由 `Scripts/HanTigers.lua` 检查是否有该晋升；刚选完到下一次刷新（战斗或回合开始）之间还没生效。

副作用：敌方少数按晋升类别判断的克制加成（如穿甲对重骑兵、梯队、Sabum Kibittum）对武将不生效；兵种克制本身按标签判断，照常生效（如抗骑兵打骑兵 +10）。

## 验收清单

- 选人界面显示汉帝国 / 刘备，三个文明特性和五位武将。
- 建立首都后，首都旁立刻出现关羽、张飞，并收到通知；`Lua.log` 有 `[HanLiuBei] ... recruited`。赵云、黄忠、马超在研究到对应科技后的下一个回合开始时出现。
- 武将阵亡后再研究任何科技都不会再出现；读档后不会重复发放。
- 进入古典时代后，战斗预览出现「五虎上将：古典时代 +8」；中世纪再多一行。**这个时代需求条件原版只在地块修改器上用过，用在玩家身上是第一次，需要重点确认。**
- 忠诚度面板里，本文明城市对周围城市的压力比同人口的其他文明高 50%；叛离的城市在本文明压力最高时直接加入，不经过自由城市。
- 统率：武将 2 格内的己方单位（含武将自己）战斗预览出现「五虎上将统率 +5」、移动力 +1；旁边同时有大将军时再多大将军的 +5 / +1；两位武将重叠不会翻倍。
- 斩首：关羽把敌人打到 20 生命值以下时，敌方单位直接消失，`Lua.log` 有 `[HanLiuBei] ... beheaded`。
- 破城：关羽「水淹七军」后打城墙的伤害和攻城槌在场时一样。
- 威震华夏：关羽杀敌后，9 格内交战城市的忠诚度立刻少 20，城市上方飘字「威震华夏 -20 忠诚度」；10 格外和未交战的城市不变。`Lua.log` 有 `Awe Over China`。
- 晋升：武将升级时打开的是专属晋升树（7 个，名字是典故），选择后效果生效；黄忠「神射」后射程 3。
- 虎将之勇：任一武将生命值打到 50 以下后，战斗预览出现「虎将之勇：生命值低于50 +7」，25 以下再多一行；回满血后消失。`Lua.log` 不应有报错。
- 机制晋升：张飞「义释严颜」击败的敌方单位变成己方；「喝断当阳桥」后相邻敌军预览出现 -7；赵云「汉水空营」后敌人只有贴脸才看得到他，「截江夺斗」后上岸不耗光移动力；「虎威将军」后范围内单位多 1 移动力；马超「羌胡归心」打死的蛮族变成己方，「收服庞德」进攻打死的骑兵变成己方；关羽「刮骨疗毒」后相邻单位每回合多回 20。
- 黄忠受伤后战斗力不下降，射程 2；赵云攻击后还能移动。
- 兴复汉室：打更强单位时预览出现 +5。占领城市的忠诚度面板有 +3。
- 蜀道：单位上丘陵只花 1 点移动；商业中心 / 工业区相邻山脉时有对应相邻加成。
- 屯田：城市详情的伟人点数里没有来自兵营和兵营建筑的大将军点数（其他来源如政策照常）；兵营 +2 生产力、每座兵营建筑再 +2。维护费比同等规模的其他文明少；兵营旁的各种改良设施都 +1 粮 +1 产，不相邻的、没有改良设施的地块没有。
- 武将模型显示正常，没有红色感叹号。

## 已知问题与限制

- 五虎将的 `TraitType` 是单独的特性 `TRAIT_LEADER_LIU_BEI_TIGER_UNITS`，不能挂在领袖能力特性上：界面（`Civ6Common.lua` 的 `GetLeaderUniqueTraits`）会把绑定了特色单位的特性当成单位，领袖能力整段就不显示了。

- 和文明征服模式一起用时：武将 `CanTrain=0`，征服者不会解锁生产；激活刘备的领袖能力只会拿到随时代成长，不会送武将（脚本按领袖类型判断）。
- 通知文本在 Gameplay 脚本里用 `Locale.Lookup` 生成（与官方黑死病剧本相同的做法），联机各电脑语言不同时，通知文字会不同，不影响游戏状态。
- 选人界面的马超图标来自风云变幻资源，如果前端没加载会显示为空。

## 开发

`Data/Promotions.sql` 和 `Data/Text.xml` 由仓库里的 `tools/han_liubei/` 生成，不要手改：晋升数据在 `promos.py`，所有中英文本在 `text.py`。改完运行：

```
python tools/han_liubei/promos_sql.py
python tools/han_liubei/text.py
```
