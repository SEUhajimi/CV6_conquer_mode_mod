# 时代分速查 / Era Score Guide

[中文](#中文) | [English](#english)

## 中文

不知道时代分怎么拿？这个 MOD 在游戏右下角的**时代进度面板**里加入“如何获得时代分”一栏：

- 顶部显示离避免黑暗时代 / 进入黄金时代还差多少分。
- 按类别（探索与建城、宗教、军事、城市与建设、科技文化与伟人、外交经济与间谍）列出所有能给时代分的历史时刻，以及每项的分值和游戏原文说明。
- 标出每项的状态：本时代还能拿（黄色）、你已获得几次、已被其他文明抢先的世界首次、只在某些时代有效的条目。
- 默认只显示还能拿的，点按钮可切换为显示全部。
- 列出本时代可选的致辞，以及它们在普通时代下额外给分的方式。

所有条目都从游戏数据读取，其他 MOD 新增的历史时刻也会自动出现在“其他”分类里。

**要求**：迭起兴衰或风云变幻规则。
**纯界面 MOD**：不改游戏数据，可以随时加入或移出已有存档。

## English

Not sure how to earn Era Score? This mod adds a "How to earn Era Score" section to the **Era Progress panel** (bottom right of the screen):

- How many points you still need to avoid a Dark Age or reach a Golden Age.
- Every historic moment that gives Era Score, grouped by category, with its score and the game's own description.
- The state of each one: still earnable this era (yellow), how many times you earned it, world firsts already taken by another civ, and moments limited to certain eras.
- Shows only earnable moments by default; a button toggles showing all of them.
- This era's dedications and the extra Era Score they give in a Normal Age.

Everything is read from the game database, so historic moments added by other mods show up under "Other".

**Requires** Rise and Fall or Gathering Storm rules.
**UI only**: it does not change game data, can be added to or removed from existing saves at any time.
