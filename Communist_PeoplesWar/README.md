# 共产党 — 神秘的红色领袖：人民战争 v0.7 测试版

这是按最新目标更新的可安装开发包，不是完成版。没有运行 Civilization VI 实机验收。

## 已接入

- 文明能力：每人口额外+1城市生产力，无需总督。
- 文明能力：每人口耗粮减少0.5（2→1.5），以每人口+0.5粮食返还，城市粮食产出里显示。
- 文明能力：建造者+1使用次数；使用次数可加速远古/古典奇观，每次推进原始生产成本的15%。

- 风云变幻的新文明「共产党」、领袖「神秘的红色领袖」，不继承中国文明能力。
- 文明能力：所有单位劫掠收益+100%；成功劫掠敌方城市所属设施/区域/建筑使人口-1，最低1。
- 文明能力：仅复用埃莉诺 SKIP_FREE_CITY 直接归降，仍需本文明忠诚压力最高，不附带巨作忠诚光环。
- 领袖能力：近战与抗骑兵移动+1、本土+5、对受损敌军+5、战斗经验+50%。
- 工农红军替代火枪手：像长生军一样兼具远程攻击（远程=近战-10，射程2，仍为近战类别）、基础移动+1、击杀回血20、移动或行动后也可按回合回血，包括敌境。
- 文明能力：原版进攻间谍任务视为高2个等级。
- 原版火枪手模型、秦始皇图标和外交场景的临时映射。

## 间谍实现

文明能力已接入原版 `MODIFIER_PLAYER_ADJUST_SPY_BONUS`，`Offense=true`、`Amount=2`：进攻任务视为高2个等级，提高成功率。机制与武则天/密码学政策相同，不依赖武则天DLC，不修改其他文明，不额外赠送间谍或增加容量。

按最新要求取消固定100%成功。反间谍仍采用原版规则，间谍仍可能失败、被发现、被捕或死亡。

## 安装

1. 删除之前的 `MaoZedong_PeoplesWar` 开发预览目录（两版沿用同一 Mod ID，不要同时保留）。
2. 将整个 `Communist_PeoplesWar` 文件夹放入：
   `文档/My Games/Sid Meier's Civilization VI/Mods/`
3. 在「额外内容」启用本 Mod，新建「风云变幻」游戏，选择共产党 — 神秘的红色领袖。
4. 使用新存档。旧版中国神秘的红色领袖存档不兼容新文明身份。

## 验收

- 1/5/10人口城市应分别额外获得1/5/10生产力；人口变化后自动更新，不要求工作地块或总督。
- 新建建造者应比原版多1使用次数；远古/古典奇观可消耗次数加速，其他时代奇观不因此解锁加速。

- 领袖界面显示共产党，而不是中国；独有项目只有工农红军。
- 近战、抗骑兵+1移动；骑兵、远程单位不获得人民战争加成。
- 己方领土和受损敌军战斗加成分别显示，条件满足时可以叠加。
- 任意本文明单位劫掠敌方设施，城市人口减少1；1人口不再下降。其他文明、道路、无所属城市地块不触发。
- 对照原版劫掠收益，检查+100%效果，以及与劫掠政策的叠加。
- 工农红军继承火枪手的科技、硝石需求、升级路线，移动力通常为4。
- 受损红军移动后在己方、中立和敌方领土都应在回合结算时恢复；击杀另恢复20。
- 对照原版间谍任务窗口，检查进攻任务等级加成和成功率；不应显示所有任务100%。
- 忠诚归降需正常忠诚压力最高，不能因本文明刚劫掠就自动归降。
- 模型、外交场景和加载资源需要实机确认。临时美术不是神秘的红色领袖专属肖像。

## 已有检查

Gameplay SQL结构与步兵继承；Configuration入口；图标映射；XML和文件引用；劫掠人口逻辑14个模拟用例。风云变幻扩展表采用模拟数据；这些检查不代替实机测试。

若加载异常，提供 `Logs/Database.log`、`Modding.log` 和 `Lua.log`。排查数据库兼容问题可提供当前游戏的 `Cache/DebugGameplay.sqlite`。

详见 `Docs/Design.md` 与 `Docs/Validation.json`。


成功劫掠改良设施、区域或其中建筑后，执行单位恢复全部生命值，属于文明能力。回血不要求目标城市还能减少人口，无所属城市的设施也能触发回血；城市人口减少仍须符合敌方城市判定且最低保留1。


## 马克思理工学院

替代学院，沿用原版学院成本、解锁科技、建筑兼容与模型。相邻加成科技值通过原版镜像机制同时提供等额信仰和生产力，不转换建筑或专家的科技产出。原版对相邻加成的修正仍遵循游戏机制。保留大科学家点数，每回合额外+1大预言家点数、+1大工程师点数。测试时检查相邻加成4的区域是否同时提供4信仰和4生产力。

每相邻一个工业区，马克思理工学院额外获得+2科技相邻加成，该加成同时镜像为信仰和生产力，叠加原版学院的普通区域相邻规则。
